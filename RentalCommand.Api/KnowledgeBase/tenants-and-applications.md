A **tenant** is a person who rents from you. You can add tenants directly, or let prospects apply to you and turn an approved applicant into a tenant.

## Add a tenant directly

1. Open **Tenants**.
2. Click **New Tenant**.
3. Enter first and last name, email, phone, and an emergency contact.
4. Click **Save Tenant**.

The Tenants list shows each person's contact info and how many active leases they have.

## Collect applications with a link

Instead of typing applicants in yourself, share an application link:

1. Open **Applications**.
2. Click **Get application link**.
3. Copy the link and send it to prospective tenants. Anyone with the link can apply — no account needed.

Submitted applications show up in the Applications list with the applicant's name, email, phone, stated monthly income, and a status (Submitted, Under Review, Approved, Declined, or Withdrawn).

## Screen an applicant

1. Open an application from the list.
2. The applicant must have **given consent** to be screened — this is shown on the application.
3. Click to run **screening**. The result includes a recommendation to help you decide.

Screening uses an outside provider. If no provider is set up, you'll see a note that screening isn't configured — you can still review and decide manually.

## Approve or decline

- **Approve** creates a tenant record from the application, so you can put them on a lease.
- **Decline** records the decision (you can add a reason).
