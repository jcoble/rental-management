The **Details** card on a property page shows a live summary rolled up from the property's units. The numbers update automatically — you never edit them directly.

## Units and occupancy

**Units** shows the total number of units attached to this property. **Occupied** is how many of those units currently have a status of *Occupied*.

A unit counts as occupied when its **Unit Status** is set to **Occupied** — not just because a lease exists, but because the unit's status has been explicitly marked that way. A unit with an active lease that's still marked *Vacant* will not count toward occupancy until the status is updated.

## Why the counts are read-only

Unit count and occupancy are computed directly from the units themselves. To change the total, add or remove a unit from the property. To change the occupancy number, update the individual unit's status — the count here reflects the change immediately.

## Other fields in Details

The Details card may also show **Year Built**, **Management Fee**, and **Notes** when values have been set on the property. Unlike the unit counts, these are editable fields — update them by opening the property's edit form.
